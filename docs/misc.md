# Miscellaneous

This document contains miscellaneous information about the BarcodeNcrypt application that does not fit into other categories.

## Password Assistant

The password assistant feature allows users to fill in password fields by scanning a barcode. This feature is intended to be a convenience, and in the future, it will be extended to augment existing password providers with barcode-based authentication.

## On-Screen Detection Service

The on-screen detection service is an accessibility service that runs in the background and watches the screen for encrypted messages. When a message is detected, the service highlights it and prepares it for decryption.

## AzNavRail

The app's navigation is handled by the AzNavRail component, a customizable navigation rail that provides a consistent and intuitive user experience. AzNavRail is an open-source project that is designed to be highly configurable and easy to use.
